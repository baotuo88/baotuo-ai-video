# baotuo-ai-video 品牌与工作台布局

- 项目品牌名称：baotuo-ai-video。
- 用户选择左侧导航、中间创作、右侧 AI 助手的工作台布局。
- 统一公共导航，保留现有业务路由、项目权限、任务通知和助手能力。
- 小屏使用导航与助手抽屉，桌面支持左右栏主动收起。
- 更新浏览器标题、登录注册入口与项目说明；保留上游版权、迁移历史、数据库名称及部署服务标识。

3. 使用业务层认证布局承载品牌，基础 components/ui 源码不修改。
4. 执行类型检查、lint、专项测试和生产构建；记录环境限制。

## 验收重点
- 项目内剧本、分镜、素材及设置可达；管理员入口遵循现有角色判断。
