# baotuo-ai-video 品牌与工作台布局完成说明

## 最终范围

用户确认采用左侧导航、中间创作、右侧 AI 助手的工作台结构。本轮完成覆盖 Dashboard 下全部业务路由的公共布局重构，以及项目品牌替换；具体剧本、分镜、素材页面内部编辑器仍使用原业务实现。

## 关键实现

- `lib/brand.ts` 与 `components/brand.tsx` 集中品牌名称和标识；更新根页面 metadata、认证页面入口、前端 package 名称、后端应用展示名称和密码重置邮件文案。
- `workspace-navigation.ts` 管理导航数据；Sidebar 显示全局入口及当前项目子导航，设置入口沿用管理员角色条件。
- AppHeader 改为品牌、主题、任务通知、助手入口和账户操作；保留 Pipeline 恢复及页面重新可见时的连接恢复。
- Dashboard 公共布局保持主 ScrollArea 按 pathname 重建、固定 Header/Sidebar、独立路由内容框；桌面侧栏首屏即预留空间，避免认证结束后宽度跳动。
- `WorkspaceAssistant` 复用会话状态、消息列表、输入区、引用与工具确认。1280px 起显示右侧助手，窄屏使用 Sheet；左右栏可主动收起，草稿持久化沿用现有状态层。
- 业务认证布局位于 `components/auth/`；未修改 `components/ui/` 下的任何基础组件。
- 设置 Turbopack 根目录，避免外层用户目录 lockfile 影响项目根目录推断。
- 根 README 增加二次开发来源和源码构建说明。保留 MIT 许可及上游署名、迁移历史、数据库标识；原镜像并不包含本轮定制。
