# 工作台可靠性与发布优化

## 范围
- 按用户、会话保留未发送附件及上传状态；防止旧上传覆盖清空后的草稿或跨账号写入。
- 桌面左右栏偏好通过 Cookie 保存，服务端读取初始状态，避免首次渲染尺寸跳变。
- 项目列表和生成工作区按内容宽度响应，适配三栏布局。
- 核查并清理无引用的旧助手浮窗；整理超限文件。
- 统一前端测试入口及发布前检查；独立 GitHub 来源使用 baotuo88/baotuo-ai-video。
- Docker Hub 命名空间尚未提供，采用显式配置及缺失时报错，不推送或部署。

## 验证
类型检查、lint、全量前端测试、生产构建、浏览器模拟接口的附件及布局回归。后端与真实模型联调以实际环境可用性为准，不把模拟接口结果等同真实验收。
