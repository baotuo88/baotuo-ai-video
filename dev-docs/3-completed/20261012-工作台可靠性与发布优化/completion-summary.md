# 工作台可靠性与发布优化完成记录

## 最终范围

在既有 baotuo-ai-video 三栏工作台基础上，完成附件可靠性、导航状态、可用宽度适配、超限文件整理及独立发布配置。独立仓库来源为 `baotuo88/baotuo-ai-video`。本次仅修改本地文件，未上传仓库、推送镜像或部署。

## 关键实现

- 内存附件 store 按用户与会话隔离，保存上传/失败状态；session 和 revision 防止注销、清空后的旧请求重新写入草稿。刷新页面会清空附件，文字草稿仍沿用原有持久化。
- 服务端读取 Cookie 初始化左右栏，用户操作同步保存偏好。应用根错误边界使用 resetKey 清除路由错误，避免 key 变化卸载整个工作台及助手。
- 项目列表使用容器查询；高级创作区按实际内容宽度切换排列。窄屏固定编辑区与结果区各自高度，避免网格轨道压缩后重叠。
- 分镜参考面板和素材详情面板拆分为职责独立组件；pipeline store 提取类型。扫描 app/components/lib 中 TS/TSX 文件，未发现超过 1000 行的文件。
- 清除无引用的旧助手浮窗组件及相关代码，整理导入与依赖警告。共享 components/ui 源码未修改。
- 新增统一前端 test/typecheck 入口与附件回归测试。质量工作流覆盖前端检查和后端集成验证；发布工作流依赖质量检查，校验版本和显式镜像仓库，使用已测试的后端 JAR。
- 版本查询来源切换至新仓库；Docker 镜像仓库必须显式配置，缺失时明确失败；缩短版本查询网络超时。部署示例及 README 同步更新。
